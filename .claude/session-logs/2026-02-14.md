# Session: 2026-02-14 (session 2)

## Goal
Build the extraction engine for the Reverse Map tool -- all parsers that take raw CSS, HTML, bookmarklet JSON, file uploads, and DTCG JSON, and produce normalized ExtractionResult objects.

## Key Decisions
- Used regex-based CSS parsing (not CSSStyleSheet API) since we parse pasted text that may not be valid in a browser context
- Character-by-character brace-matching parser handles nested @media, @supports, @layer, @container rules; skips @keyframes blocks
- HTML parser uses a hidden sandboxed iframe with getComputedStyle() to extract actual rendered values
- Bookmarklet is vanilla ES5 JavaScript for maximum browser compatibility
- File parser routes by extension (.css, .html/.htm, .json) and auto-detects DTCG vs bookmarklet JSON by checking for $value keys
- All parsers sort output by count (frequency) descending for importance ranking
- rem/em values assumed 16px base for conversion to pixels
- Shadow parsing correctly handles multi-layer shadows with paren-respecting comma splitting

## What Changed
- `/src/tools/import/reverse-map/extraction/types.ts` -- shared types (ExtractedColor, ExtractedFontSize, ExtractedFontFamily, ExtractedSpacing, ExtractedShadow, ExtractedMotion, ExtractionResult) + emptyResult helper
- `/src/tools/import/reverse-map/extraction/parseCSS.ts` -- 706-line regex-based CSS parser: colors (hex/rgb/hsl/oklch/named), fonts, spacing (incl. shorthand), shadows, motion (duration/easing), custom properties, nested at-rules
- `/src/tools/import/reverse-map/extraction/parseHTML.ts` -- iframe-based DOM walker with getComputedStyle(), extracts colors/fonts/spacing/shadows/motion/custom properties
- `/src/tools/import/reverse-map/extraction/parseBookmarkletData.ts` -- parses bookmarklet JSON output, handles all property types
- `/src/tools/import/reverse-map/extraction/parseDTCGJson.ts` -- W3C DTCG token format parser with alias resolution, handles color/dimension/fontSize/fontFamily/shadow/duration/cubicBezier/transition/typography types
- `/src/tools/import/reverse-map/extraction/parseFile.ts` -- file upload router (.css/.html/.htm/.json) with DTCG auto-detection
- `/src/tools/import/reverse-map/extraction/index.ts` -- barrel export
- `/public/bookmarklet.js` -- self-contained vanilla JS bookmarklet that walks all page elements, extracts computed styles, collects CSS custom properties, copies JSON to clipboard

## Goal
Add token-driven interactive animations to all 3 demo sites (SaaS landing, Dashboard, Blog) so users can test motion tokens via real interactions.

## Key Decisions
- All transitions use `m.easingStandard` and `m.durationFast`/`m.durationNormal` from the shared motion module (CSS custom properties that reflect DSW token values)
- Button press uses scale(0.96) to stay subtle but noticeable
- Pricing toggle uses a custom toggle switch rather than a checkbox for visual consistency
- Price animation uses a CSS @keyframes animation with token-driven duration/easing
- Table row hover uses inline event handlers (onMouseEnter/onMouseLeave) to set border-left and background, matching the existing pattern in the codebase
- Blog code block copy uses navigator.clipboard API with a 2s revert timer
- Related articles 3D tilt uses perspective(600px) rotateY(2deg) rotateX(-1deg) for a subtle effect
